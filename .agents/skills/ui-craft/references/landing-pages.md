# Landing pages that have a soul

A clean, well-animated site can still feel generic. A typical AI-built SaaS page says who it is
for and then designs like it has never met them: no imagery, generic icons, stepwise copy.

## Relate to the audience first

- Show the audience's world: a restaurant tool shows kitchens, tablets on counters, printed
  menus; a freelancer tool shows laptops and desks. **No images anywhere is the tell of a
  vibe-coded site.**
- One actionable headline that promises exactly what the product does.
- Presentation beats complexity: skewed product cards, edited screenshots of the real product
  (an analytics view, a password-protected link) instead of icon grids.

## Build a visual identity before layout

1. Start from one image with the right mood; crop, darken, add noise, set the name on it.
2. Collect a few more images in the same mood; pull a palette from them (plus 1–2 accents).
3. Add texture that belongs to the domain (counter, utensils, a device in context).
4. Type: keep a good sans for UI copy; add a characterful serif for display if the brand wants
   personality (a printed menu). Drop monospace unless the product is for developers.
5. A small set of custom icons in the accent colours that stand for the main features.
6. None of this comes from a formula — choose what conveys the feeling of the brand.

## "Frankenstein" the wireframe

Pick sections from sites you admire for *structure only*, write down the change you want for
each (bigger images, less text, left-aligned, less blocky), assemble them, then throw away
everything except the wireframe. Example flow: hero → rotating logo ribbon → how it works with
big contextual images → features as full-width coloured tabs with large images and 90% less
text → testimonials → bold CTA over an image → footer.

## Fill the wireframe with the identity

- Hero: brand colour or image background, light noise (also helps text contrast), large
  split heading, subtext, rounded buttons spaced at least twice the heading→subtext gap,
  scattered imagery that is actually structured (large below, small on top, a safe margin
  around text), darkened edges to pull focus to the centre.
- Alternate section treatments (image + strong noise; cream + no noise + graph-paper texture)
  so the page has rhythm.
- Because layout and identity are separate, swapping the identity gives a wholly different
  feel on the same wireframe.

## Motion with a theme

- Pick one or two motion ideas and repeat them site-wide (e.g. a section pulling away and
  blurring as the next slides over; gradient transitions between sections). Motion directs the
  focal point — fix hard breaks between sections with it.
- Rotate important feature images on a timer; subtle zoom on hover.
- A load-more beats infinite scroll; scroll-jacking almost never.

## Copy and conversion

- Prefer a giant input as the hero for tools where trying it *is* the pitch.
- Social proof: logos plus a few real testimonials.
- Pricing: few plans; the price is the biggest thing, the plan name small; show the actual
  discount and what the next plan adds.
