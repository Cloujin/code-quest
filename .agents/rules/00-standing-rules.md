# Standing rules — Code Quest

The rules live in `CLAUDE.md` at the repository root, and `AGENTS.md` is their short form. Read
`AGENTS.md` before any work here, then the files its table names.

- Ask before inventing product logic.
- No comments in code.
- `type(scope): subject`, a branch and a pull request, never `main`, no assistant attribution.
- The gate before every commit: `npm run check`.
- Two people, two agents: read `COLLABORATION.md` and run `npm run team` first. Claim work with a draft pull request. Never merge without the other person's approval.
